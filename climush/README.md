# climush toolkit for collaborative research

## Publish
The `publish` module of the `climush` package contains tools that facilitate 
the dissemination of the types of data that the CliMush project produces.

### Sequence Data

#### Sequence Read Archive (SRA)

The climush package can upload files to the SRA using the NCBI's File 
Transfer Protocol (FTP) server.

#### NCBI BioProject

The National Center for Biotechnology Information (NCBI) created the 
BioProject database in 2011, intended to replace NCBI's Genome Project 
database. A BioProject is a data bundle that includes all data 
generated by a given organization of researchers.

BioProjects include the following attributes, which describe the scope, 
research methods, and objects of the project:
* sample scope
* material
* capture
* method
* objective

According to NCBI, a BioProject itself is not sufficient for publication. 
The data associated with the BioProject must also be submitted to an 
appropriate INSDC database, such as GenBank.

BioProject records can be accessed using NCBI's Entrez programming utilities,
however, all communications are GET methods (i.e., there are no apparent PUT 
or POST methods via Entrez).
